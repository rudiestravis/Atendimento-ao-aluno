# Atendimento ao Aluno – Etec Prof. Dr. José Dagnoni

Sistema web de atendimento ao aluno da Etec (Santa Bárbara D'Oeste), desenvolvido com Vibe Coding para a disciplina de Desenvolvimento de Sistemas.

## Funcionalidades
- Abertura de solicitações (documentos, acadêmico, benefícios, sugestões)
- Geração de número de protocolo
- Consulta de andamento pelo protocolo
- Perguntas frequentes (FAQ)
- Painel da secretaria: filtros, resposta e alteração de status
- Identidade visual da Etec / Centro Paula Souza (vermelho e cinza-azulado)

## Tecnologias
HTML5, CSS3 e JavaScript puro. Os dados ficam no `localStorage` do navegador.

## Como executar
Abra o arquivo `index.html` no navegador.

## Logo
Coloque a imagem do logo em `assets/logo-etec.png`. Se ela não existir, o site exibe uma versão em texto.
